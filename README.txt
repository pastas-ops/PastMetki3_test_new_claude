В папке www/index.html лежит само приложение PastMetki (один HTML-файл).
Его можно:
 1) загрузить в онлайн-конвертер HTML -> APK, или
 2) собрать через GitHub (вкладка Actions, файл .github/workflows/build.yml), или
 3) открыть проект в Android Studio (npm install, npx cap add android, npx cap open android).

Обновление поверх старой версии:
 - debug.keystore в корне проекта - фиксированный ключ подписи. Все APK, собранные через
   GitHub Actions с этим файлом, подписаны одним ключом и устанавливаются поверх друг друга.
 - versionCode (с 1.1.0) = минуты с 1970 года: всегда растёт, даже если вы создали новый репозиторий. Раньше он
   брался из номера запуска GitHub, и в новом репозитории обнулялся - тогда Android отказывался ставить «более старую» версию.
 - в логе сборки (шаг Verify APK) печатается отпечаток подписи; если он не 10:FA:54:3F... - APK подписан другим ключом.
 - APK называется pastmetki-ВЕРСИЯ.apk (файл в Artifacts и в Releases репозитория), версия берётся из package.json.
 - Если на телефоне уже стоит PastMetki, собранная раньше с ДРУГИМ ключом, один раз удалите её,
   потом ставьте новую.

Версия 1.1.0 (ОБЯЗАТЕЛЬНО перед первым запуском):
 1) Firebase Console -> Firestore -> Rules: вставьте весь firestore.rules из проекта и нажмите Publish
    (добавлены коллекции eco, counters, files - без них монеты, ID профиля и вложения не работают).
 2) Выложите сайт (firebase deploy --only hosting или workflow «Deploy site»): версия 1.0.x проверяет обновления по
    https://pastmetki.web.app/version.json. Если файла там нет, проверка пишет «не удалось проверить».
    Версия 1.1.0 дополнительно ищет обновление в GitHub Releases (workflow сам создаёт релиз с APK).
 - пункты плана: у каждого можно поставить дату (и время); пункт появляется в календаре как дедлайн, рядом кнопка «К плану»
   (ведёт в календарь на дедлайн плана, а если у плана дедлайна нет - в сам план); отметка пункта отмечает его и в плане;
 - вложения: фото, документы (до 640 КБ), ссылки (до 8 + 8) к заметкам, сообщениям чатов и групп. Файлы лежат в Firestore
   (коллекция files), миниатюры - в самой заметке. Бесплатно, без Firebase Storage (он требует платный тариф Blaze);
 - виджеты не грузились из-за простого <View> в layout (RemoteViews его не поддерживает) - заменено; сборка теперь падает,
   если <View> вернётся; виджет заметок получил новый вид текста (название, подпись, прогресс 2/5);
 - монеты, серия, покупки и друзья-бонусы лежат в отдельном документе eco/{uid} и меняются транзакциями. Остальные данные
   пишутся через mergeFields, поэтому чужие/старые версии приложения больше не могут затереть монеты;
 - профиль: новая карточка (как на скриншоте), ID (000001...), корона (ID 1 или поле cr=1 в profiles), кнопка
   «Как видят вас другие», новая карточка чужого профиля, редактирование с одной кнопкой «Сохранить» (всплывает стеклянной
   плашкой, если настоящая кнопка внизу); добавлен сет Gold;
 - главная: ячейки одного размера, цвет плана не обрывается, новый вид прогресса, цвета прогресса и быстрых действий
   (шестерёнка на главной); чаты: стеклянные шапка и поле ввода; шапка плавно скрывается в профиле и чатах;
 - экран больше не перерисовывается целиком: обновляются только изменившиеся элементы (morphHTML).
 - живой огонёк (вместо бегущего): огонёк с глазками и ножками. Режимы: сидит на аватарке / поднимает и опускает её ручками / стоит у ника /
   держит своё число вместо квадратика с огоньком. В «Редактировать профиль» выбирается один режим или «Случайно» (меняется при каждом открытии профиля).
   Пока огонёк надет, статичный квадратик рядом с монетами не показывается (кроме режима «держит число»). Огонёк серый и с закрытыми глазами, если сегодня не было заметки;
 - магазин: 10 новых анимированных фонов (сцены и узоры с персонажами, нарисованы SVG), 13 узорных рамок аватарки, 11 рамок описания,
   новые стили сообщений и скины огонька; старые предметы подешевели в 3-5 раз; новые сеты Инь-Ян, Футбол, Планета, Пончик, Котик
   (огонёк-инь-ян / мячик / планета / пончик / котик + рамка + фон + сообщения + рамка описания). Старые сеты из продажи убраны, купленное осталось у владельцев.
 - Чтобы у вас был ID 000001: до того, как зайдут другие, в Firestore вручную поставьте profiles/<ваш uid>.pid = 1
   и counters/users.n = 1.
 - Потерянные монеты: откройте Firestore -> users/<uid>: если там ещё лежат старые поля coins/pinv/fire/rf, при первом
   запуске 1.1.0 они скопируются в eco/<uid> сами. Если полей нет, поправьте число вручную в eco/<uid>.coins.

САЙТ (ПК + телефон, те же аккаунты и данные)
Сайт - это та же папка www/ (index.html, manifest.webmanifest, sw.js, иконки). Хостинг Firebase бесплатный (тариф Spark).
Один раз:  npm i -g firebase-tools   ->   firebase login
Дальше из папки проекта:  firebase deploy
Эта команда публикует и сайт, и firestore.rules. Адрес сайта: https://pastmetki.web.app (и pastmetki.firebaseapp.com),
эти домены уже разрешены для входа. Другой домен (свой или github.io) нужно добавить в Firebase ->
Authentication -> Settings -> Authorized domains. Вариант без консоли: GitHub Pages (workflow "Deploy site", запуск вручную).
На телефоне сайт можно установить как приложение (меню браузера -> «Добавить на главный экран»).


ОБНОВЛЕНИЯ ПРИЛОЖЕНИЯ
Приложение при запуске читает файл www/version.json с сайта (SITE в index.html, по умолчанию https://pastmetki.web.app).
Поля: version - последняя версия; min - минимальная допустимая (всё, что старее, блокируется экраном «Нужно обновить»);
page - ссылка, куда отправлять за обновлением (например, пост или канал в Telegram); apk - ПРЯМАЯ ссылка на .apk (необязательно:
тогда приложение скачает файл само, останется нажать на уведомление и «Установить»); notes - список изменений.
Как выпустить обновление:
 1) залейте проект в GitHub - соберётся APK (подпись у всех сборок одна и та же, debug.keystore в проекте, поэтому APK ставится поверх старого);
 2) скачайте APK из Actions и выложите в свой канал;
 3) в www/version.json поставьте новую version, notes и ссылку на пост в page;
 4) опубликуйте сайт (firebase deploy или «Deploy site») - после этого приложения увидят обновление.
Чтобы запретить старую версию - поставьте min равным новой версии. Если сайт лежит не на pastmetki.web.app, поменяйте SITE в index.html.
Проверка обновлений отключается в Настройках; «Что нового» открывается нажатием на версию в Профиле.
