# Статистика PastMetki (для итогов года)

Статистика ведётся автоматически и хранится в документе пользователя в Firestore: `users/{uid}`, поле `st`.
Отдельных прав или правил не требуется. Данные по годам, поэтому «итоги 2026» можно собрать в декабре.

Структура `st`:

- `y["2026"]` - счётчики за год:
  - `nc` - создано заметок (вкладка «Заметки»)
  - `nd` - выполнено заметок (в т.ч. заметки из чатов и общие)
  - `dd` - выполнено дедлайнов (заметок, у которых была дата)
  - `ld` - выполнено после дедлайна (просрочено на момент выполнения)
  - `ti` - выполнено пунктов плана (задач внутри заметок)
  - `fr` - новые друзья (с момента первого запуска версии 1.0.8)
  - `ms` - отправлено сообщений
  - `mt` - сообщений за год по каждому чату: `{ "<чат или g_группа>": { n: число, l: "имя" } }`
- `dn`, `pi`, `fs` - служебные: что уже посчитано (чтобы отмена галочки возвращала счётчик назад), список друзей.

Если выполнение отменить (снять галочку), счётчики уменьшаются обратно; повторное выполнение считается один раз.

Готовая сводка: в консоли браузера (сайт) команда `pmStats()` или `pmStats("2026")` возвращает объект:
`notesCreated, notesDone, deadlinesDone, doneAfterDeadline, planItemsDone, newFriends, messagesSent,
messagesTotal, messagesBusiestChat {count, name}`.

Ограничения: друзья, добавленные до версии 1.0.8, и сообщения, отправленные до неё, в `ms` не попадают;
количество сообщений по чатам (`mt`) считается по реальным данным чатов за текущий год, поэтому оно точное.
